# Что запрещено в сборке. Читает Паровозинг.
#
# Формат: шаблон|причина для игрока, по одному на строку.
# Шаблон ищется в имени файла (в нижнем регистре) в папках mods/ и resourcepacks/.
#
# Найденный файл не удаляется, а переносится в parovozing-disabled.
# Игра его не грузит, но игрок видит, куда он делся, и может вернуть, если шаблон сработал зря.
#
# Сюда идут только явные читы: чит-клиенты и то, что годится только для жульничества.
#
# Не сюда: миникарты (JourneyMap, Xaero, VoxelMap), фуллбрайт и гамма, фрикам, литематика, шейдеры.
# Это не читы, разрешать их или нет решает владелец сервера.
#
# Essential тоже не сюда. Он не чит, просто без лицензии бесполезен, поэтому его не кладут в сборку
# (EXCLUDE в scripts/pack-build.py). Если запретить его здесь, его отберут и у тех, у кого лицензия есть.
#
# Короткие шаблоны опасны. «map» снёс бы все миникарты, «light» моды на освещение, «gamma» настройки гаммы.
# Шаблон должен быть таким, чтобы не совпасть случайно.
