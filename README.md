# AMDH-Mine — модпак

Сборка модов для сервера **AMDH-Mine** (Minecraft 1.21.1, NeoForge).

Здесь лежат только метаданные: названия модов, ссылки на Modrinth и контрольные
суммы. Сами `.jar` не хранятся — они скачиваются напрямую с Modrinth.

## Файлы

| Файл | Что это |
|---|---|
| `pack.toml`, `index.toml`, `mods/` | пак в формате packwiz |
| `manifest.txt` | то же в построчном виде, для обновлятора |
| `blacklist.txt` | список запрещённых модов |

Два формата рядом не случайно: packwiz понимают готовые инструменты, а
построчный манифест читается штатными средствами Java без единой сторонней
библиотеки — обновлятору не нужен парсер, а значит и сборка с зависимостями.

## Как обновляется

Сборка правится в Prism Launcher, затем на машине сервера запускается
`scripts/pack-build.py`. Он пересобирает этот каталог из инстанса, поднимает
версию пака и подтягивает версию NeoForge с сервера — сервер здесь источник
истины, клиенты подстраиваются под него.

## Русификатор

`files/amdh-rus-*.jar` - мод без кода с недостающим русским переводом модов сборки.
Исходники в `rus/`: `translations/` - только дописанные строки, `src/` - готовые
`ru_ru.json` (родной перевод мода плюс дописанное) и `neoforge.mods.toml`.
Мод грузится после переводимых модов, иначе английские строки в их
собственных `ru_ru.json` перебивали бы перевод.

Пересобрать после правок в `rus/src`:

```bash
cd rus/src && jar --create --file ../../files/amdh-rus-X.Y.Z.jar --manifest META-INF/MANIFEST.MF -C . assets -C . META-INF/neoforge.mods.toml
```

После этого обновить хеш и имя файла в `manifest.txt` и `mods/amdh-rus.pw.toml`.

## Обновление самого Паровозинга

Новая версия кладётся в `files/` и добавляется в `manifest.txt` как обычный
`mod`, а старые помечаются `ban` по началу имени файла (`parovozing-1.2` и т.п.).
Старый Паровозинг скачивает новый и сам переносит себя в `parovozing-disabled`.
Даже если старый файл не удалось убрать, NeoForge при одинаковом modId
загружает самую новую версию, а она уже убирает старую.

Следующая версия: добавить `ban` на текущую (например `parovozing-1.3`).
