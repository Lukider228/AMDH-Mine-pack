# AMDH-Mine — модпак

Сборка модов для сервера **AMDH-Mine** (Minecraft 1.21.1, NeoForge).

Здесь лежат только метаданные: названия модов, ссылки на Modrinth и контрольные
суммы. Сами `.jar` не хранятся — они скачиваются напрямую с Modrinth.

## Файлы

| Файл | Что это |
|---|---|
| `pack.toml`, `index.toml`, `mods/` | пак в формате packwiz |
| `manifest.txt` | то же в построчном виде, для обновлятора |
| `blacklist.txt` | список запрещённых модов |

Два формата рядом не случайно: packwiz понимают готовые инструменты, а
построчный манифест читается штатными средствами Java без единой сторонней
библиотеки — обновлятору не нужен парсер, а значит и сборка с зависимостями.

## Как обновляется

Сборка правится в Prism Launcher, затем на машине сервера запускается
`scripts/pack-build.py`. Он пересобирает этот каталог из инстанса, поднимает
версию пака и подтягивает версию NeoForge с сервера — сервер здесь источник
истины, клиенты подстраиваются под него.

## Подключение

Адреса сервера и инструкцию по установке спрашивай у владельца.
